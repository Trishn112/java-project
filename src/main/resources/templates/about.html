ℹ️ System Architecture & Algorithm

Technical breakdown of the 100% Java-based intelligent recommendation engine, object-oriented architecture, and scoring mechanics.

1. Recommendation Scoring Formula

The recommendation engine employs an explainable, data-driven weighted composite scoring formula where all factors are normalized to a standard [0.0, 1.0] scale:

Final Score = (Preference Score × 0.40) + (Category Match Score × 0.20) + (Item Rating Score × 0.25) + (Popularity Score × 0.15)
1. Preference Score (40%)

Normalized user affinity for the candidate item's category: userPreference / 5.0.

2. Category Match (20%)

Evaluates whether the candidate item's category matches the user's positive preference profile.

3. Quality Rating (25%)

Normalized average item rating: itemRating / 5.0.

4. Community Popularity (15%)

Normalized interaction counter: popularity / 100.0.

2. Object-Oriented Design & Clean Architecture

OOP Concepts Implemented

  • Encapsulation: Private fields with validated getters and setters across all model classes.
  • Inheritance & Polymorphism: Admin extends User; ContentBasedRecommender extends RecommendationEngine.
  • Interfaces & Contracts: Recommender interface defines the abstract recommendation contract.
  • Composition / Association: Item HAS-A Category; Rating HAS-A User and Item.

Collections & Generics

  • List<Item>, List<Recommendation>: Type-safe ordered sequences.
  • Set<Integer> ratedItemIds: O(1) deduplication & previous rating exclusion.
  • Map<Category, Double>: O(1) constant-time user taste preference lookups.
  • Comparator.comparingDouble(): Descending sort by calculated score.

3. Academic & Viva Defense Summary

Is this Machine Learning?
No. It is an intelligent, data-driven, content-based recommendation algorithm written in 100% Java using Object-Oriented Programming, Java Collections, and Generics.

Key Personalization Feature:
Different users receive distinct rankings according to their category preferences. Items already rated by the target user are excluded from new recommendation sets.
